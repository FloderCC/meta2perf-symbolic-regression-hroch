# Archived experiment logs

| File | Description |
|---|---|
| `hroch/archived/run.log` | Final unscaled HROCH symbolic-regression metrics and equation. |
| `baselines/dataset_only/archived/run.log` | Five reference regressors using only dataset descriptors. |
| `random_forest_shap/archived/run.log` | Joint random-forest metrics, selected parameters, and KernelSHAP output. |

The withdrawn min-max experiments are intentionally absent. The historical
symbolic-regression log records completion but not the start time, so exact
wall-clock duration cannot be recovered.

This index was moved from the original logs directory. Log contents and
historical timestamps are unchanged. New logs are stored with the corresponding
experiment run; see [the output index](README.md).
