# Archived experiment logs

| File | Description |
|---|---|
| `symbolic_regression.txt` | Final unscaled HROCH symbolic-regression metrics and equation. |
| `dataset_only_meta_regressors.txt` | Five reference regressors using only dataset descriptors. |
| `joint_random_forest_shap.txt` | Joint random-forest metrics, selected parameters, and KernelSHAP output. |

The withdrawn min–max experiments are intentionally absent. The historical
symbolic-regression log records completion but not the start time, so exact
wall-clock duration cannot be recovered.
